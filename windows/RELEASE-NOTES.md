# AnyWay 0.1.3

本版修复 Mac 和 Windows 的地图、参数与安装体验。两个桌面端及各自的 Android 配套 APK 使用相同产品版本。

## 修复内容

- Mac：路径点现在可通过按下、拖动、松开来调整位置；拖动中同步预览路线，松开后保存坐标。
- Windows：修正设备下拉框的箭头按钮、边框及圆角样式。
- Windows：滚动右侧菜单时，悬停在数值框上不再误改参数。点击对应数值框后可用滚轮调节，离开该输入框后恢复菜单滚动。
- Windows：安装包默认使用 `AnyWay` 目录，不再沿用旧版 `WinLS` 安装路径；启动时隐藏控制台窗口。
- Mac：pkg 安装后将 `AnyWay.app` 放入 `/Applications`。

使用须知：本软件仅供研究学习与开发测试，请遵守设备及所测试服务的使用规则。
